Status: spike baseline, 2026-06-30.

This map tracks production behavior by user-facing path first, then by current
test evidence. The goal is to keep modernization work honest while replacing
legacy dependencies.

## Modernization Gate

Before claiming production-ready:

1. Keep the full suite green.
2. Add tests for monitoring instance type initialization and URL providers.
3. Add fake-server HTTP behavior tests for at least one legacy CGI server and one JSON API server.
4. Keep dependency removals verified by focused tests, full tests, and app build.
5. After each category: run focused tests, full tests, app build.
6. Before claiming production-ready: launch the app, capture log evidence, and record remaining signing/notarization limits.
7. Before public distribution: sign with `script/sign_release.sh`, notarize and staple with `script/notarize_release.sh`, then package with `script/package_release.sh --developer-id --skip-build`.

Current remaining CocoaPods: none. Active scalar settings, filters, server login
preferences, and monitoring instances no longer use Realm. Existing
Realm-backed user configuration uses an explicit cutoff report in this Realm-free
build unless a separate bridge build or external migration tool is provided.
