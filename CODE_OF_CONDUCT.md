# Code of Conduct

## Standard

Participants are expected to keep project discussion respectful, technical, and
actionable.

Good participation includes:

- using clear reproduction steps;
- separating facts from assumptions;
- accepting maintainer decisions on scope;
- avoiding personal attacks, harassment, or discriminatory language.

Unacceptable behavior includes:

- harassment or threats;
- publishing private information;
- posting credentials, tokens, or private monitoring data;
- repeated off-topic or hostile comments after a maintainer asks for a change.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or
decline contributions that violate this policy.

## Reporting

Report conduct issues privately to the maintainer through the repository owner
contact path. Security issues should follow `SECURITY.md`.
