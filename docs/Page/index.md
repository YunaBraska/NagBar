# NagBar

A native macOS status-bar client for Nagios-compatible monitoring systems.

[Documentation](documentation.html) | [Install](install.html) | [Source](https://github.com/YunaBraska/NagBar)

## What it does

- Reads host and service status from Nagios, Icinga, Icinga 2, Thruk and Check_MK.
- Exposes current problems from the macOS menu bar.
- Exercises first-run behavior against a loopback Icinga server in tests.

## Availability

NagBar is a maintained revival. Its signed and notarized external delivery path is being prepared before a supported public release.

## Requirements

NagBar supports macOS 12.4 and later.
